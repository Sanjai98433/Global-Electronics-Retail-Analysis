# Global Electronics Retail — Sales Analysis Dashboard

## 📊 Project Overview

This project analyzes sales performance for a global electronics retail business using Power BI.

The dashboard provides an interactive view of sales, profit, orders, customers, product performance, and country-level performance.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Modeling
- Data Visualization

## 📈 Dashboard Features

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Average Order Value
- Profit Margin
- Monthly Sales Trend
- Top 10 Products by Sales
- Sales by Category
- Sales by Country
- Profit by Category
- Top 10 Customers by Sales
- Sales vs Profit by Category
- Year and Country filters

## 🔍 Key Insights

- Total sales reached 55.76M with 32.66M in total profit.
- The United States is the largest sales market in the current dashboard view.
- Computers are the leading category by sales and profit.
- Monthly sales show noticeable variation throughout the year.
